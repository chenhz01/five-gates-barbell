# Weekly review — the light end, once a week

Fifteen minutes. One table. One decision per row.

## 1. Attention split check

| End | Target | Actual this week | Delta |
|---|---|---|---|
| Heavy (cash flow, operations) | 85–90% | | |
| Light (experiments) | 10–15% | | |

If the light end exceeded 15%, cut something this week. The rule is not
aspirational.

## 2. Light-end ledger

| Bet | Started | Cost so far | Signal (countable) | Stop-loss condition | Decision |
|---|---|---|---|---|---|
| | | | | | graduate / hold / cut |

Decision definitions:

- **Graduate** — the countable signal hit a level where it deserves heavy-end
  time. Move it, do not just "keep an eye on it".
- **Hold** — one more week, with a written checkpoint. Holding twice in a row
  without a new signal is a cut.
- **Cut** — stop. Write why. The reason goes in the rejection log.

## 3. Rejection log additions

| Killed this week | Red gate(s) | Reason |
|---|---|---|
| | | |

## 4. One question

> Did anything this week pass a gate that should have been red?

If yes, the gate needs adjusting, or the evidence standard was lowered to let
something through. Both are worth writing down.
